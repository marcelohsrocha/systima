Importar do Trello

1. De onde vêm os dados?

No Trello, abra o quadro → Menu (⋯) → Imprimir, exportar e compartilhar → Exportar como JSON. Salve o arquivo e selecione abaixo.

Atenção: a exportação JSON do Trello traz no máximo os 1.000 comentários mais recentes. Se o quadro tiver mais comentários do que isso, use a conexão direta.

Puxa tudo, inclusive todos os comentários. Gere a chave e o token em trello.com/power-ups/admin: crie um Power-Up, gere a API key e clique em Token. O token é usado só nesta importação e não fica salvo.
